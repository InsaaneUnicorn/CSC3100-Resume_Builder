Attribution and AI Use

ResumeCraft is built with Electron, Node.js, Express, SQLite, Bootstrap, and vanilla JavaScript.

Generative AI support is optional. If a user provides a Gemini API key, the app sends only the text entered in the review box to Gemini for resume suggestions. No developer API key is bundled.
