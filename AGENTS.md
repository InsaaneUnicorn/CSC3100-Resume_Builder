
# AGENTS.md

## Overview

This file documents the agents available in this project, their purposes, and usage guidelines. This project is an **AI-powered Resume Builder ElectronJS App**, and agents are designed to automate, enhance, or streamline tasks such as resume content generation, user data processing, and workflow automation within the ElectronJS environment.

---


## Agent Directory

### 1. Default Agent
- **Purpose:** Handles general coding tasks, file edits, and project scaffolding for the Resume Builder ElectronJS App.
- **Usage:** Invoked automatically for most user requests unless a specialized agent is specified. Supports tasks such as UI updates, backend logic, and integration of AI features for resume generation.

### 2. Explore Agent
- **Purpose:** Fast, read-only codebase exploration and Q&A, with a focus on the ElectronJS and AI-powered features of the app.
- **Usage:** Use for searching, reading, and summarizing code or documentation. Specify thoroughness (quick/medium/thorough) as needed. Useful for understanding how AI modules, ElectronJS components, and resume generation logic interact.
